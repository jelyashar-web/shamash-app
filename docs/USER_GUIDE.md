# מדריך משתמש - מערכת שמש

## ברוכים הבאים למערכת שמש

**שמש** היא מערכת ניהול בית כנסת מתקדמת שפותחה להקל על עבודת הגבאים וניהול הקהילה. המערכת עובדת גם ללא אינטרנט ושומרת את כל המידע באופן מקומי.

## התחלה

### דרישות מערכת

- דפדפן מודרני (Chrome, Firefox, Safari, Edge)
- חיבור אינטרנט לסנכרון (לא חובה לשימוש בסיסי)
- מסך בגודל מינימלי של 768px (תומך גם בטאבלטים ומובייל)

|-------|--------|-------|

## התחברות למערכת

1. פתחו את הדפדפן ונווטו לכתובת המערכת
2. הזינו את האימייל והסיסמה
3. לחצו על "התחבר"

### שכחתי סיסמה

אם שכחתם את הסיסמה, פנו למנהל המערכת לאיפוס.

## לוח הבקרה

לוח הבקרה מציג סיכום של כל הפעילות בבית הכנסת:

### יתדען כללי

- **מספר חברים**: כמות החברים הרשומים במערכת
- **עליות השבוע**: עליות לתורה ששובצו לשבת הנוכחית
- **תרומות חודשיות**: סכום התרומות בחודש הנוכחי
- **אירועים קרובים**: אירועים הקרובים בלוח השנה

### זמני היום

בחלקו העליון של המסך מוצגים זמני היום לפי מיקום בית הכנסת:
- עלות השחר
- זמן טלית ותפילין
- נץ החמה (הנץ)
- שקיעת החמה
- צאת הכוכבים

## ניהול חברים

### צפייה ברשימת חברים

1. לחצו על "חברים" בתפריט הראשי
2. תוצג רשימת כל החברים במערכת
3. ניתן לחפש חברים בשורת החיפוש
4. ניתן לסנן לפי קטגוריה (כהן, לוי, ישראל)

### הוספת חבר חדש

1. לחצו על כפתור "חבר חדש"
2. מלאו את הפרטים הבאים:
   - **שם מלא** (חובה)
   - **טלפון**
   - **אימייל**
   - **קטגוריה**: כהן / לוי / ישראל
   - **תאריך יאורצייט**: בתבנית MM-DD
   - **הערות**: מידע נוסף על החבר
   - **תמונה**: העלאת תמונת פרופיל
3. לחצו על "שמירה"

### עריכת חבר

1. לחצו על כרטיס החבר ברשימה
2. ערכו את השדות הרצויים
3. לחצו על "שמירה"

### מחיקת חבר

> **שימו לב!** מחיקת חבר תמחק גם את ההיסטוריה שלו (עליות, תרומות).

1. פתחו את עמוד החבר
2. לחצו על כפתור "מחיקה"
3. אשרו את המחיקה

### קטגוריות חברים

| קטגוריה | תיאור | הרשאות בעליות |
|---------|-------|---------------|
| כהן | בני אהרון הכהן | קדושה ראשונה |
| לוי | משבט לוי | קדושה שנייה |
| ישראל | שאר ישראל | שלישי ואילך |

## עליות לתורה

### צפייה בעליות

1. לחצו על "עליות" בתפריט
2. בחרו את התאריך הרצוי בלוח השנה
3. יוצגו העליות לתורה לתאריך זה

### שיבוץ עלייה

1. לחצו על "עלייה חדשה"
2. בחרו:
   - **תאריך**: יום הקריאה בתורה
   - **חבר**: מבחר רשימת החברים
   - **סוג עלייה**: כהן / לוי / שלישי / רביעי / חמישי / שישי / שביעי / מפטיר
   - **פרשה**: שם הפרשה (אופציונלי)
3. לחצו על "שמירה"

> **טיפ:** המערכת תציג התראה אם מנסים לשבץ חבר לא עלייה המתאימה לקטגוריה שלו.

### סוגי עליות

| סוג | תיאור | זכאות |
|-----|-------|-------|
| כהן | עליית כהנים | בני אהרון בלבד |
| לוי | עליית לויים | בני לוי בלבד |
| שלישי | שלישי | כל חבר |
| רביעי | רביעי | כל חבר |
| חמישי | חמישי | כל חבר |
| שישי | שישי | כל חבר |
| שביעי | שביעי | כל חבר |
| מפטיר | מפטיר | כל חבר |

### דוח עליות

ניתן להפיק דוח PDF של העליות לשבוע נבחר:
1. בחרו תאריך
2. לחצו על "הפק דוח"
3. הדוח יורד למחשב

## תרומות

### רישום תרומה

1. לחצו על "תרומות" בתפריט
2. לחצו על "תרומה חדשה"
3. מלאו את הפרטים:
   - **חבר**: התורם
   - **סכום**: בסך שקלים
   - **תיאור**: מטרת התרומה
   - **תאריך**: תאריך קבלת התרומה
   - **סטטוס**: שולם / לא שולם
4. לחצו על "שמירה"

### סיכום תרומות

בעמוד התרומות מוצג:
- סה"כ תרומות בחודש הנוכחי
- תרומות לפי חבר
- תרומות לפי תקופה

### סינון תרומות

ניתן לסנן תרומות לפי:
- תאריך (מתאריך - עד תאריך)
- חבר מסוים
- סטטוס תשלום (שולם / לא שולם)

## הוצאות

### רישום הוצאה

1. לחצו על "הוצאות" בתפריט
2. לחצו על "הוצאה חדשה"
3. מלאו את הפרטים:
   - **קטגוריה**: חזן / רב / מזון / תחזוקה / חשמל ומים / ציוד / משכורות / אחר
   - **ישלם ל**: שם המקבל
   - **תיאור**: פירוט ההוצאה
   - **סכום**: בסך שקלים
   - **תאריך**: תאריך ההוצאה
   - **סטטוס**: שולם / לא שולם
   - **הערות**: מידע נוסף
4. לחצו על "שמירה"

### קטגוריות הוצאות

| קטגוריה | דוגמאות |
|---------|---------|
| חזן | שכר חזן, שכר קריאה בתורה |
| רב | שכר רב, הכשרות |
| מזון | קידושים, סעודות מצווה |
| תחזוקה | תיקונים, ניקיון |
| חשמל ומים | חשבונות שוטפים |
| ציוד | ספרים, כלי בית |
| משכורות | משכורות עובדים |
| אחר | הוצאות שונות |

## אירועים

### הוספת אירוע

1. לחצו על "אירועים" בתפריט
2. לחצו על "אירוע חדש"
3. מלאו את הפרטים:
   - **כותרת**: שם האירוע
   - **תאריך ושעה**
   - **תיאור**: פירוט האירוע
   - **סוג**: תפילה / חג / מפגש / כללי
4. לחצו על "שמירה"

### סוגי אירועים

- **תפילה**: מנחה, ערבית, שחרית
- **חג**: חגים ומועדים
- **מפגש**: אסיפות, שיעורים
- **כללי**: אירועים שונים

## זמני היום

המערכת מחשבת אוטומטית את זמני היום לפי מיקום בית הכנסת:

| זמן | תיאור |
|-----|-------|
| עלות השחר | התחלת יום חדש |
| טלית ותפילין | זמן הדלקת נרות בשבת |
| הנץ | זמן תחילת זמן קריאת שמע |

## הגדרות

### הגדרות מערכת

1. לחצו על "הגדרות" בתפריט
2. ניתן לשנות:
   - שם בית הכנסת
   - לוגו
   - כתובת
   - קואורדינטות (לחישוב זמני היום)

### שינוי סיסמה

1. לחצו על שם המשתמש בפינה העליונה
2. בחרו "שינוי סיסמה"
3. הזינו את הסיסמה הנוכחית והסיסמה החדשה
4. לחצו על "שמירה"

## פותר בעיות

### בעיות התחברות

**הודעה: "שם משתמש או סיסמה שגויים"**
- בדקו שהקלדתם את האימייל נכון
- ודאו שאין רווחים מיותרים
- נסו להקליד את הסיסמה במקום אחר והדביקו

### בעיות סנכרון

**המידע לא מתעדכן בכל המכשירים**
1. בדקו חיבור לאינטרנט
2. רעננו את הדף
3. התנתקו והתחברו מחדש

### בעיות תצוגה

**הטקסט לא מופיע נכון**
- ודאו שהדפדפן מעודכן
- נסו לרענן את הדף (F5)
- נקו את המטמון (Ctrl+Shift+R)

### יצירת קשר

לתמיכה טכנית, פנו למנהל המערכת.

## טיפים וקיצורי דרך

### קיצורי מקלדת

| פעולה | קיצור |
|-------|-------|
| חיפוש | Ctrl + K |
| שמירה | Ctrl + S |
| רענון | F5 |

### טיפים

1. **חיפוש מהיר**: השתמשו ב-Ctrl+K לפתיחת חיפוש מכל מקום
2. **תמונות**: העלו תמונות ברזולוציה של עד 500KB לביצועים טובים
3. **גיבוי**: ייצאו את הנתונים באופן תקופתי מההגדרות
4. **RTL**: המערכת תומכת בעברית - ודאו שהמקלדת מוגדרת לעברית
